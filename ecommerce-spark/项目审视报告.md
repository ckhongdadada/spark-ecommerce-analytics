# 项目审视报告

> 更新日期：2026-04-07
> 项目名称：电商全路径数据分析系统

## 已完成修复

1. 统一时区配置
说明：在 `SparkSessionFactory` 中统一设置 `spark.sql.session.timeZone=Asia/Shanghai`，避免模块一、二、三的时间口径不一致。

2. 修复 Streaming checkpoint 位置
说明：checkpoint 已从 `readStream` 移到 `writeStream`，Kafka 和 Socket 使用独立子目录。

3. 明确 `all` 模式行为
说明：`all` 现在明确表示“全部批处理模块”，不再暗示会自动跑 Streaming。

4. 修复模块一重复运行失败
说明：写出 `output/cleaned` 前会自动删除旧目录，便于重复演示。

5. 修复 GraphX 顶点 ID 方案
说明：取消哈希映射，改为 `zipWithUniqueId` 为用户分配唯一顶点 ID，消除碰撞风险。

6. 完善性能调优模块对比口径
说明：缓存、普通 Join、广播 Join、加盐 Join 改为多次采样输出，更接近可解释的对比实验。

7. 补充基础工程化能力
说明：新增 `build-local.ps1`、本地 Maven 仓库、JUnit 基础测试用例。

## 当前剩余限制

1. 模拟数据仍是演示数据
说明：`DataGenerator` 还没有构造真实 session、订单链路和用户长期偏好，结论更适合课堂演示而不是业务复盘。

2. Streaming 仍是演示型实现
说明：目前输出目标仍是控制台，适合本地展示，不是生产消费链路。

3. 性能调优模块不是严格 benchmark
说明：虽然已经加入多次采样，但还没有接入 SparkListener、系统级监控和更大规模压测。

## 建议的后续优化顺序

1. 把模拟数据升级为带 session 和转化链路的行为序列
2. 为 SQL 和 GraphX 输出增加固定落盘结果，方便答辩截图与复核
3. 为 Streaming 增加文件或 Kafka sink，补齐“输入-处理-输出”闭环
4. 继续补充 `src/test/scala`，优先覆盖 ETL、SQL 报表和配置校验
