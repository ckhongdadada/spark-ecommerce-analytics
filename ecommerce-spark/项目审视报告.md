## 二、代码质量提升总结

| 指标 | 改进前 | 改进后 |
|------|--------|--------|
| **日志框架** | `println` | `slf4j` + `logback` |
| **配置管理** | 硬编码 | 支持环境变量 |
| **缓存策略** | 无 | `persist()` + `unpersist()` |
| **Hash 算法** | `hashCode` (有冲突风险) | `Murmur3Hash` |
| **类别不平衡** | 未处理 | 类别权重 |
| **Streaming 容错** | 无 Checkpoint | 支持 Checkpoint |
| **Kryo 注册** | 1个类 | 7个类/类型 |
| **自适应查询** | 未启用 | AQE 已启用 |
| **数据验证** | 无 | case class 内置验证 |
| **配置验证** | 无 | 启动时自动验证 |
| **MySQL 写入** | 单条写入 | 批量写入 + 并行分区 |

## 六、数据模型验证规则

### 6.1 UserBehaviorLog

| 字段 | 验证规则 |
|------|----------|
| userId | 非空 |
| itemId | 非空 |
| category | 非空 |
| behavior | 必须是 `pv`、`buy`、`cart`、`fav` 之一 |
| timestamp | 必须大于 0 |

### 6.2 CleanBehavior

| 字段 | 验证规则 |
|------|----------|
| hour | 0-23 范围内 |
| dayOfWeek | 1-7 范围内 |
| isWeekend | 必须是 0 或 1 |

### 6.3 SalesReport

| 字段 | 验证规则 |
|------|----------|
| totalPV | 非负数 |
| totalBuy | 非负数 |
| convRate | 0-100 范围内 |

| Logger | 级别 | 说明 |
|--------|------|------|
| `com.ecommerce` | DEBUG | 项目代码详细日志 |

| Appender | 说明 |
|----------|------|
